# 🌐 OtterDuckness - Personal Website
 
This repository contains my personal website:  
👉 https://mikhailtolubaev.com
 
It’s a photography portfolio built with my own images, created to showcase and promote my hobby.
 
---
 
## 📌 Description
 
This project is a static website where I present my photography work, including portraits, events, and street photography.
 
The goal was to build something simple, clean, and personal — not just functional, but visually consistent with my style.
